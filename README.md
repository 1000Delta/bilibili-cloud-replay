# B站云端回放分段助手

用于B站直播中心的 Tampermonkey / Violentmonkey 用户脚本。当前版本 **0.8.2**。

## main 新增：投稿合集管理（尚未发布 Release）

在回放列表工具栏或详细面板的任务页点击 **投稿合集管理…**，可以按投稿标题识别候选分组，一次确认后新建合集并导入视频，也可以为已有合集追加新投稿。识别和预览不会修改 B 站数据。

候选分组默认收纳，摘要显示 **关键词 · 新建/追加 · 视频数量**；点击 **展开 / 收纳** 查看或隐藏详情。不同分组轮换使用淡蓝、淡绿、淡橙、淡紫底色，展开后的编辑区另有浅色分层。

逐视频 `view` 详情检查现为可选项，**默认关闭**。默认直接使用已读投稿列表中的封面创建合集，不再因列表旧标题与当前稿件标题不一致而中断；导入时仍读取必要的基础分P信息取得 CID。

## 功能

- 默认只扫描当前页的已结束云端直播回放，逐场显示详情，缓存录像范围，融入原回放列表操作。
- 每段最多 1:59:50，为转码时长偏移留出余量。
- 默认标题为“直播主题 YYYY-MM-DD NN”；跨零点沿用开始直播日期，同日同主题跨场次连续编号。
- 单场、跨页多选、逐段确认标题与封面；按时间顺序提交，失败跳过，保留窗口供手动重试。
- 保存所选关键帧时间，支持原时间重新取图；临时图片在确认后先上传为稳定地址，再用于投稿。
- 根据实际文件头识别 JPEG、PNG、WebP，兼容图片服务返回 `application/octet-stream`。
- 明确失败任务可以重置，保留编号；处理中、成功或结果不明任务不会盲目重发。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 新建脚本，使用仓库中的 [bilibili-cloud-replay.user.js](bilibili-cloud-replay.user.js) 完整内容覆盖并保存。
3. 打开 [B站直播回放页](https://link.bilibili.com/p/center/index#/my-room/live-record)。
4. 更新时覆盖原脚本并保留存储，不要并行启用多个版本。

## 使用

扫描不会投稿。选择回放后，核对每段标题、时间、封面，再点击“确认并开始投稿”。该按钮会执行图片上传及视频投稿，稿件之后可能公开可见。

- “重新随机”更换画面，“按原时间取图”保持已选时间。
- 失败项可单独重试；“停止后续”保留尚未处理的片段，已发出的请求无法撤销。
- 账号只在扫描前确认一次；切换登录账号后先重新扫描。
- 日常扫描只读取当前页回放，先读一页切片记录并逐场取录像详情，再按需补读切片页，核对本页全部场次；不遍历其他回放页。已发布片段标签只读取当前切片页。
- 本页已投稿/处理中范围全部覆盖后即停止补读；仍有未覆盖范围时，会继续核对到切片记录末尾，确认未投稿或部分投稿。若尚未遍历全部切片记录，打开投稿确认窗口前仍会补全去重与最终编号；此时不会上传或投稿。后续复用核对结果；“刷新任务”可手动完整更新。
- 投稿前复用扫描范围，不重复请求 `GetSliceStream`。
- 请求前间隔默认 100ms，可设为 0–60000ms。它独立于正常至少30秒、4001后至少60秒的投稿冷却。

图片读取失败时最多按原时间自动重新取图一次。若持续出现网络或CORS错误，可在确认窗口手动切换请求方式；不会自动切换后重复投稿。

## 隐私与限制

凭证从当前已登录页面临时读取，没有内置Cookie、CSRF、GitHub令牌或密钥。脚本直接与B站接口交互，没有第三方后端或遥测服务。本地账本会记录账号、片段、标题、封面时间和任务状态。

诊断、HAR、截图与原始接口响应可能包含账号及内容信息，请勿直接提交到公开仓库。具体规则见 [SECURITY.md](SECURITY.md)。

非官方工具，接口可能变化。服务端受理不代表审核通过或最终视频可播放。转码可能增加成片时长；预留余量不能保证所有情况下都严格小于2小时。上传或投稿失败不会自动重发，异常稿件需后续人工核对。

## 稿件编辑

- 投稿窗口取得稿件 avid 后显示“继续编辑稿件”；只有切片 ID 时先刷新投稿状态，不能把切片 ID 当成稿件 ID。
- 0.8.1：单份稿件打开后自动读取最新详情，无需再点击读取；加载期间不能保存，失败后可手动重试。批量入口仍先选择需要读取的稿件。
- 0.8.1：编辑请求按创作中心的保存结构构造，转换 `human_type2.id`、`recreate.switch`、`subtitle.allow → open`、水印和视频分P字段，并添加 `new_web_edit: 1` 等网页编辑标记；不再把详情响应直接展开提交。
- 历史投稿列表工具栏及详细面板任务页有“批量编辑稿件”入口。范围是本工具扫描到的云端回放投稿；先选稿再读取最新元数据。
- 单稿支持标题、标签和普通文本简介。标题括号 `（）`、`【】`、`()`、`[]` 可提取候选；嵌套只取最内层，错配清空当前括号栈，空项忽略，Unicode NFC 去重。候选默认不选中，勾选后可编辑并追加，已有标签保留。
- 批量规则支持标题文字替换/前后缀、标签追加/移除、简介追加/替换。应用规则始终基于本次读取的原值；重复点击不会重复追加，但重新应用会覆盖下方手工草稿，请先应用规则再手工微调。
- 点击“生成修改前后预览”，核对后再“确认保存预览中的修改”。更改草稿或请求方式会使旧预览失效。
- 保存串行执行，每项前至少间隔一秒；可停止后续项。发送前复读完整元数据，发现变化则标记冲突，重新打开编辑器读取并预览。
- 编辑使用当前登录账号，核对稿件归属，保留封面、分区、全部分P以及支持的字幕、水印、可见性等编辑设置；详情页的统计、状态等只读字段不会提交。未返回完整视频元数据或关键设置格式无法识别时不会保存。富文本简介变更被拦截，请去创作中心处理，避免损坏提及信息。
- 网络异常先回读；已受理/结果不明项只允许核对，不能自动重发。发送前将固定目标保存在账号独立账本的 `editJobs` 中，页面重开仍防止重复追加。明确拒绝可再次确认同一预览，重试的仍是固定目标。
- 编辑接口与审核状态独立；“已回读确认”只证明目标字段已读到，不表示审核通过。服务端没有条件写入机制，复读与提交之间仍有极短竞争窗口，请避免同时在多个工具编辑同一稿件。

读取遇到 CORS 时可在编辑器手动选择“扩展 HTTP”。不会在 POST 异常后自动切换通道重试。标题沿用项目已存在的 80 字符验证；未猜测新增标签/简介的数量或长度限制，平台业务错误会逐项显示。

## 弹幕时间轴与手动分段

在“确认投稿”窗口中点击对应场次的 **弹幕与切片**。只有尚未尝试投稿的片段可调整；队列启动后禁用此入口。

1. 统一时间轴在每处分界提供一个可拖动手柄；相邻片段共用分界，拖动时两边时间实时更新。每段下面保留 `HH:MM:SS` 输入框，时间从本场开播算起，支持超过24小时。相邻片段原本相接时，移动边界会同步调整另一段。可以从中间拆段或移除不需要的段。
2. 点击“读取本场弹幕”，显示开播后时间、用户、弹幕。支持用户/内容搜索，每页50条；时间轴按分钟聚集，悬停显示前12条摘要，点击可查看该分钟全部弹幕。也支持导入本地 ASS 文件。
3. 核对 ASS 零点相对开播的偏移（秒，可为负），勾选时间对应确认。设置弹幕前后秒数和专题主题，再点击该弹幕的“拆出片段”。例如前60秒、后30秒会将当前段拆为前段、90秒专题段、后段；超出当前段时截断至边界并提示。可移除前后段，只保留专题。
4. 点击“应用分段并重新确认投稿”，重新核对标题、时间和封面，再明确确认投稿。应用分段本身没有上传或投稿操作。取消不更改计划；调整仅在当前页面计划中保留，重新扫描会恢复自动分段。

所有切片仍不得超出选中的录像范围、跨越录像缺口或重叠；保留每段1:59:50上限、开播日命名和已有投稿拦截。专题段替换原范围的一部分，不允许绕过重复投稿规则从已投稿范围重复截取。编号使用原持久账本，新范围可能产生跳号；已用编号不回收。范围或主题改变后重新生成标题并核对封面，未变片段保留标题草稿。

弹幕接口依据 B站[官方云剪辑页面](https://live.bilibili.com/web-cut/quick-publish.html)公开前端的 `GetLiveSessionData` 与 `ass_url` 用法；文件仅从 HTTPS `hdslb.com` CDN 匿名读取，不将签名地址或弹幕内容存入账本、缓存或诊断。ASS 的 `Name` 字段为空时显示“未提供”，不会从内容猜测用户身份。文件最大8 MiB、最多100000条。没有弹幕文件或下载失败时显示原因，可手动选择原有扩展HTTP请求方式或导入 ASS，不自动切换。

**时间对应限制：** ASS 是相对时间，真实返回的零点和缺口处理尚待账号实测；默认偏移为0不代表已校准。必须先对照官方回放核对。有录像缺口时，拼接播放器时间可能不等于开播相对时间；若不能用固定偏移对应，请不要通过该弹幕自动定位，改用手动核实的时间。用户名是否存在取决于平台文件。

发布准备检查：`npm run check`、144项合成/模拟测试通过；没有访问真实账号弹幕、上传封面或执行真实投稿。平台权限、ASS实际字段和时间偏移仍需按实际场次核对。单元测试在 `tests/timing.test.cjs`，此前的浏览器交互结果在 `tests/ui/results.json`，不代表此次重新执行了 UI 检查。

时间轴支持1×、2×、4×、8×缩放；窄屏横向滚动。聚焦手柄后，方向键移动1秒，Shift + 方向键移动10秒，Home/End到达允许边界。拖动取消会恢复本次拖动前的两侧时间；手柄不能跨越相邻分界或录像缺口。编辑时允许临时超过1:59:50，超长片段标红并禁用应用按钮；继续拆分后方可应用，投稿时长上限保持不变。

组件方案参考：[noUiSlider 多手柄](https://refreshless.com/nouislider/slider-values/)适合无框架网页；[Shoelace](https://shoelace.style/)支持Web Components/CDN。当前保留零依赖，将专用时轴和弹幕轨道直接封装在现有 Shadow DOM 中，无需安装组件库或在运行时加载第三方脚本。

### 分界关键帧预览

悬停或聚焦时间轴分界手柄，会在时轴下方显示关键帧截图；拖动、键盘微调或手动修改分界时间后，停下350毫秒再读取。截图显示返回的关键帧时间，实际画面可能位于所选时间附近；结束边界使用最后一个可用秒。读取复用现有关键帧接口，仅查看，不上传、不投稿，也不修改投稿封面。请求串行执行，过时结果不覆盖新位置；窗口内最多缓存32个时间点，关闭后丢弃，不保存到诊断。读取或图片加载失败可点击“重新读取截图”。真实平台截图与定位精度仍需账号实测。

### 关键帧悬停放大

确认投稿窗口的封面（随机关键帧或默认封面）和“弹幕与切片”的分界关键帧，均支持鼠标悬停或 Tab 聚焦后放大查看。放大层完整显示原图、保持比例，并限制在当前窗口内；支持 Popover 的浏览器中不会被列表或对话框滚动区域裁切。鼠标可移入放大层继续查看，移开后关闭；按 Esc 或点击放大层的“关闭”仅收起图片，不关闭编辑窗口。滚动、窗口尺寸变化、换图或关闭页面内窗口时自动清理预览。

放大复用已显示图片的地址，不额外调用关键帧接口，不改变所选封面、分段或投稿状态。此次检查通过 `npm run check`、144 项合成单元测试，以及隔离 Edge 在 1280×1000 和 480×900 窗口中的 81 项 UI 检查；涵盖键盘聚焦、延迟加载、连续换图、Esc、滚动、缩放与关闭清理。未操作真实账号、上传图片或投稿。

### 当前页交错扫描

- 请求顺序为当前页回放 → 当前页号的已有切片 → 本页各场录像详情 → 按需补全本页场次对应的切片记录。列表、每场详情及投稿状态陆续显示，扫描完成前不允许提交。
- 默认跟随 B 站当前页码与每页数量；翻页或切换标签自动核对新页面，5 分钟刷新也只处理当前页。页码、数量与可见卡片身份必须一致，不能识别时提示重试，不猜测页码或退回全局扫描。
- 快速翻页时，旧请求返回后不覆盖新页，也不会继续读取旧页剩余详情。相同卡片数量的前后页仍会更新选择按钮。已勾选的跨页场次保留最多 15 分钟，未勾选场次不继续占用当前计划。
- 回放页按场次分页，切片页按片段分页，两者不一一对应。会补读尚未读取的切片页，直到本页每场录像范围均已有投稿/处理中记录覆盖，或全部切片记录核对完毕，不再让最后几场停在“待完整核对”。已读切片页复用，已发布片段标签仍只读当前页。
- 未遍历全部切片页时，自动标题暂作预览，不提前占用新编号；打开确认窗口前仍需完成全部去重，再显示最终标题。不同页未选择的未投稿场次不参与当前计划排序，已确定的历史编号继续保留。
- “刷新当前页”强制刷新本页范围与切片记录。切片去重失败、分页漂移或识别不唯一时，保留拦截，不上传封面、不投稿。已发布片段的来源仅在已扫描场次中匹配，不为查来源扫描全部回放。

## 投稿合集管理

### 操作步骤

1. 点击 **投稿合集管理…**。此功能会明确读取全部云端回放投稿、当前账号的全部合集及各章节完整成员，不受回放列表当前页限制，也不扫描其他回放录像详情。范围是本工具的云端回放投稿，不包含账号其他来源的普通投稿。
2. 自动识别标题括号中的主题、去掉 `YYYY-MM-DD NN` 后的共同主题，以及与已有合集名称匹配的关键词。匹配忽略全角/半角、大小写和多余空格，英文关键词不会把 Java 和 JavaScript 混为一组；不会仅凭“直播”“回放”等通用词猜分组。新合集自动候选需要至少两份不同稿件，已有合集匹配一份新稿件即可出现。
3. 需要时填写 **自定义关键词**，选择新建或某个已有合集。自定义关键词只保留在本窗口，也支持仅一份视频的新建候选。候选分组默认收纳且不选中，收纳栏显示关键词、新建/追加及视频数量；展开并勾选分组后，可逐份取消视频、调整目标、编辑新合集名称与简介。摘要会随目标和视频选择更新，部分取消时显示“已勾选数量/候选总数”。展开或收纳不会改变选择、草稿或已生成的预览。已有合集有多个章节时必须明确选择章节。
4. 点击 **生成合集变更预览**。直接用本窗口已读取的投稿和合集数据生成本地方案，不请求账号、稿件详情或封面；反复点击、修改名称/简介/选择后重新预览，都不会逐视频重读。预览展示合集名称、章节和全部选中视频；新合集的封面来源固定为第一份所选稿件。同一视频匹配多个分组时，必须只保留一个目标。
5. **确认前逐视频详情检查**默认关闭，选择会显示在预览中，切换后必须重新预览。关闭时不调用 `archive/view`，不比较回放列表旧标题与当前稿件标题，不提前核对审核或互动状态；创建使用第一份所选稿件的列表封面。开启时才限速读取完整 `view`，检查稿件归属、公开审核状态、单P、互动状态、标题、CID和封面。标题不一致时会说明具体稿件及原因。此选择只在当前窗口生效，重开恢复关闭。
6. 核对方案后，再点 **确认创建并导入 / 追加**。两种模式都会重新核对账号和完整合集成员、串行写入，每次写入和视频读取前至少等待一秒，并遵守更大的自定义间隔。默认模式先创建免费合集、读取默认章节，再通过 `archive/videos` 为每份稿件读取导入接口必填的 CID；不会把切片 ID 当 CID，也不会猜选多P。关闭检查不等于完全零请求，平台仍会判断导入资格。开启模式会先检查全部视频再创建，并在逐条导入前复核。已有合集仅添加新成员，不移动或删除成员、不修改原稿件标题或已有排序。
7. 完成后点击 **重新读取投稿与合集**，重新识别后续新投稿。没有自动定时添加，也不会在普通后台扫描时创建或修改合集。

### 防重复与失败恢复

- 完整分页核对全部合集，按章节真实成员去重，不使用列表中的部分预览成员判断。列表总数变化、章节成员数量不完整或归属不一致时停止操作。
- 创建和导入前始终核对合集成员及账号；完整稿件详情由可选检查控制。写入串行执行，每次前至少等待一秒。可点 **停止后续**，已经发出的请求无法撤销。
- 预览不代表服务器资格核对通过。默认模式复用已读封面，导入前取得当前 CID；已取得 CID 后重试时若分P变化会停止。开启详情检查时，还检查创建到导入之间的标题和封面变化。两种模式都不会用未知 CID 提交；基础分P信息或完整详情返回 `-702` 时停止整批后续请求，不自动重试。
- 默认模式若缺少有效列表封面，会在创建前停止并提示开启检查或手动建合集，不会偷偷启用 `view`。创建成功后若读取 CID 或平台导入失败，可能保留空合集或部分成功合集；再次确认复用已返回的合集 ID，不会重复创建。也可重新读取并选择该已有合集继续导入。
- 每次写入前在账号独立账本保存任务。网络超时、非 JSON 响应和 HTTP 异常都视为结果不明，不自动重发或切换请求通道；服务端明确拒绝才允许再次确认重试。
- **只核对未完成结果**可在刷新页面或重开窗口后回读导入结果。已成功的同一预览不会重复执行。修改选择、名称、简介、请求方式或逐视频检查选项会使预览失效。
- 创建已返回合集 ID，但默认章节或导入失败时，不会重新创建；保留已创建合集和已成功视频，不执行删除式回滚。可重新读取并选择现有合集继续导入。
- 创建结果不明且没有返回 ID 时，不根据相似名称猜测创建成功，也不能靠改名重新创建包含相同视频的合集。请到创作中心核对；若已创建，重新读取后手动选择该合集。结果不明的导入同样先核对原目标，不会改投另一个合集。
- 平台没有原子“核对并写入”接口。最后一次核对与写入仍有短暂间隙，请勿同时用多个工具编辑合集或切换账号。

### 接口与验证范围

使用创作中心 `https://member.bilibili.com/x2/creative/web` 下的 `/seasons`、`/season`、`/season/section`、`/season/add`、`/season/section/episodes/add`；不是空间“系列/列表”或收藏夹接口。创建使用表单，添加视频使用包含 `sectionId`、`episodes` 的 JSON，AID、CID、章节 ID 使用可安全表示的数字。默认模式新增读取 `https://member.bilibili.com/x/web/archive/videos` 获取必填CID，依据[视频基础信息说明](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/creativecenter/videos.md#视频基础信息)；列表封面来自[回放投稿列表](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/live/live_replay.md)的 `av_cover`。不使用可移动稿件的 `season/switch` 接口。CSRF 仍只从当前会话临时读取，不保存。

接口结构依据[公开接口说明](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/creativecenter/season.md)与[独立实现](https://github.com/Yuelioi/bpi-rs/blob/main/src/creativecenter/season/action.rs)交叉核对。说明中部分参数表和实际示例不同，代码采用与独立实现一致的结构。平台开通资格、容量、审核、封面规格和最新接口兼容性尚未用真实账号验证。复用稿件封面仍需实际平台确认；如果封面被拒绝，请先在创作中心创建符合要求的合集，再在工具中选择已有合集导入。服务端拒绝原因会逐项显示，不会猜测或绕过平台限制。
