# B站云端回放分段助手

用于B站直播中心的 Tampermonkey / Violentmonkey 用户脚本。当前开发版本 **0.8.1（编辑保存修复待用户实测验证，未发布 Release）**。

## 功能

- 自动发现已结束的云端直播回放，缓存录像范围，融入原回放列表操作。
- 每段最多 1:59:50，为转码时长偏移留出余量。
- 默认标题为“直播主题 YYYY-MM-DD NN”；跨零点沿用开始直播日期，同日同主题跨场次连续编号。
- 单场、跨页多选、逐段确认标题与封面；按时间顺序提交，失败跳过，保留窗口供手动重试。
- 保存所选关键帧时间，支持原时间重新取图；临时图片在确认后先上传为稳定地址，再用于投稿。
- 根据实际文件头识别 JPEG、PNG、WebP，兼容图片服务返回 `application/octet-stream`。
- 明确失败任务可以重置，保留编号；处理中、成功或结果不明任务不会盲目重发。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 新建脚本，使用仓库中的 [bilibili-cloud-replay.user.js](bilibili-cloud-replay.user.js) 完整内容覆盖并保存。
3. 打开 [B站直播回放页](https://link.bilibili.com/p/center/index#/my-room/live-record)。
4. 更新时覆盖原脚本并保留存储，不要并行启用多个版本。

## 使用

扫描不会投稿。选择回放后，核对每段标题、时间、封面，再点击“确认并开始投稿”。该按钮会执行图片上传及视频投稿，稿件之后可能公开可见。

- “重新随机”更换画面，“按原时间取图”保持已选时间。
- 失败项可单独重试；“停止后续”保留尚未处理的片段，已发出的请求无法撤销。
- 账号只在扫描前确认一次；切换登录账号后先重新扫描。
- 投稿列表仅初始完整检查，后续复用；需要更新服务器结果时手动刷新。
- 投稿前复用扫描范围，不重复请求 `GetSliceStream`。
- 请求前间隔默认 100ms，可设为 0–60000ms。它独立于正常至少30秒、4001后至少60秒的投稿冷却。

图片读取失败时最多按原时间自动重新取图一次。若持续出现网络或CORS错误，可在确认窗口手动切换请求方式；不会自动切换后重复投稿。

## 隐私与限制

凭证从当前已登录页面临时读取，没有内置Cookie、CSRF、GitHub令牌或密钥。脚本直接与B站接口交互，没有第三方后端或遥测服务。本地账本会记录账号、片段、标题、封面时间和任务状态。

诊断、HAR、截图与原始接口响应可能包含账号及内容信息，请勿直接提交到公开仓库。具体规则见 [SECURITY.md](SECURITY.md)。

非官方工具，接口可能变化。服务端受理不代表审核通过或最终视频可播放。转码可能增加成片时长；预留余量不能保证所有情况下都严格小于2小时。上传或投稿失败不会自动重发，异常稿件需后续人工核对。

- 历史投稿列表工具栏及详细面板任务页有“批量编辑稿件”入口。范围是本工具扫描到的云端回放投稿；先选稿再读取最新元数据。
- 单稿支持标题、标签和普通文本简介。标题括号 `（）`、`【】`、`()`、`[]` 可提取候选；嵌套只取最内层，错配清空当前括号栈，空项忽略，Unicode NFC 去重。候选默认不选中，勾选后可编辑并追加，已有标签保留。
- 批量规则支持标题文字替换/前后缀、标签追加/移除、简介追加/替换。应用规则始终基于本次读取的原值；重复点击不会重复追加，但重新应用会覆盖下方手工草稿，请先应用规则再手工微调。
- 点击“生成修改前后预览”，核对后再“确认保存预览中的修改”。更改草稿或请求方式会使旧预览失效。
- 保存串行执行，每项前至少间隔一秒；可停止后续项。发送前复读完整元数据，发现变化则标记冲突，重新打开编辑器读取并预览。
- 编辑使用当前登录账号，核对稿件归属，保留封面、分区、全部分P以及支持的字幕、水印、可见性等编辑设置；详情页的统计、状态等只读字段不会提交。未返回完整视频元数据或关键设置格式无法识别时不会保存。富文本简介变更被拦截，请去创作中心处理，避免损坏提及信息。
- 网络异常先回读；已受理/结果不明项只允许核对，不能自动重发。发送前将固定目标保存在账号独立账本的 `editJobs` 中，页面重开仍防止重复追加。明确拒绝可再次确认同一预览，重试的仍是固定目标。
- 编辑接口与审核状态独立；“已回读确认”只证明目标字段已读到，不表示审核通过。服务端没有条件写入机制，复读与提交之间仍有极短竞争窗口，请避免同时在多个工具编辑同一稿件。

读取遇到 CORS 时可在编辑器手动选择“扩展 HTTP”。不会在 POST 异常后自动切换通道重试。标题沿用项目已存在的 80 字符验证；未猜测新增标签/简介的数量或长度限制，平台业务错误会逐项显示。

## 弹幕时间轴与手动分段（开发中，待真实账号验证）

在“确认投稿”窗口中点击对应场次的 **弹幕与切片**。只有尚未尝试投稿的片段可调整；队列启动后禁用此入口。

1. 统一时间轴在每处分界提供一个可拖动手柄；相邻片段共用分界，拖动时两边时间实时更新。每段下面保留 `HH:MM:SS` 输入框，时间从本场开播算起，支持超过24小时。相邻片段原本相接时，移动边界会同步调整另一段。可以从中间拆段或移除不需要的段。
2. 点击“读取本场弹幕”，显示开播后时间、用户、弹幕。支持用户/内容搜索，每页50条；时间轴按分钟聚集，悬停显示前12条摘要，点击可查看该分钟全部弹幕。也支持导入本地 ASS 文件。
3. 核对 ASS 零点相对开播的偏移（秒，可为负），勾选时间对应确认。设置弹幕前后秒数和专题主题，再点击该弹幕的“拆出片段”。例如前60秒、后30秒会将当前段拆为前段、90秒专题段、后段；超出当前段时截断至边界并提示。可移除前后段，只保留专题。
4. 点击“应用分段并重新确认投稿”，重新核对标题、时间和封面，再明确确认投稿。应用分段本身没有上传或投稿操作。取消不更改计划；调整仅在当前页面计划中保留，重新扫描会恢复自动分段。

所有切片仍不得超出选中的录像范围、跨越录像缺口或重叠；保留每段1:59:50上限、开播日命名和已有投稿拦截。专题段替换原范围的一部分，不允许绕过重复投稿规则从已投稿范围重复截取。编号使用原持久账本，新范围可能产生跳号；已用编号不回收。范围或主题改变后重新生成标题并核对封面，未变片段保留标题草稿。

弹幕接口依据 B站[官方云剪辑页面](https://live.bilibili.com/web-cut/quick-publish.html)公开前端的 `GetLiveSessionData` 与 `ass_url` 用法；文件仅从 HTTPS `hdslb.com` CDN 匿名读取，不将签名地址或弹幕内容存入账本、缓存或诊断。ASS 的 `Name` 字段为空时显示“未提供”，不会从内容猜测用户身份。文件最大8 MiB、最多100000条。没有弹幕文件或下载失败时显示原因，可手动选择原有扩展HTTP请求方式或导入 ASS，不自动切换。

**时间对应限制：** ASS 是相对时间，真实返回的零点和缺口处理尚待账号实测；默认偏移为0不代表已校准。必须先对照官方回放核对。有录像缺口时，拼接播放器时间可能不等于开播相对时间；若不能用固定偏移对应，请不要通过该弹幕自动定位，改用手动核实的时间。用户名是否存在取决于平台文件。

本次检查：`npm run check`、140项合成/模拟测试、57项隔离Chrome交互检查通过。没有访问真实账号弹幕、上传封面或执行真实投稿；平台权限、ASS实际字段和时间偏移仍需用户验证。新增单元测试在 `tests/timing.test.cjs`，UI结果在 `tests/ui/results.json`。

时间轴支持1×、2×、4×、8×缩放；窄屏横向滚动。聚焦手柄后，方向键移动1秒，Shift + 方向键移动10秒，Home/End到达允许边界。拖动取消会恢复本次拖动前的两侧时间；手柄不能跨越相邻分界或录像缺口。编辑时允许临时超过1:59:50，超长片段标红并禁用应用按钮；继续拆分后方可应用，投稿时长上限保持不变。

组件方案参考：[noUiSlider 多手柄](https://refreshless.com/nouislider/slider-values/)适合无框架网页；[Shoelace](https://shoelace.style/)支持Web Components/CDN。当前保留零依赖，将专用时轴和弹幕轨道直接封装在现有 Shadow DOM 中，无需安装组件库或在运行时加载第三方脚本。

### 分界关键帧预览

悬停或聚焦时间轴分界手柄，会在时轴下方显示关键帧截图；拖动、键盘微调或手动修改分界时间后，停下350毫秒再读取。截图显示返回的关键帧时间，实际画面可能位于所选时间附近；结束边界使用最后一个可用秒。读取复用现有关键帧接口，仅查看，不上传、不投稿，也不修改投稿封面。请求串行执行，过时结果不覆盖新位置；窗口内最多缓存32个时间点，关闭后丢弃，不保存到诊断。读取或图片加载失败可点击“重新读取截图”。真实平台截图与定位精度仍需账号实测。
